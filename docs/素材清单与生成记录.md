# KIBO 首页与探索舱素材清单

## 1. 生成方式

- 生成器：Codex 内置 `imagegen`。
- 统一风格：明亮、精致的卡通电影渲染，2D 素材配合 2.5D DOM 分层；圆润未来工业设计；橙、青、奶白主色；面向 10–12 岁学生，但不低幼。
- 构图约束：16:9 横向主场景；不生成文字、徽标、按钮或伪界面；重要主体避开实际网页文字区。
- 运行时处理：保留 PNG 源文件；页面使用 WebP。KIBO 与前景层先生成纯洋红背景版本，再去色键得到透明 Alpha。

## 6. 动效分层边界

- 首页只移动背景、KIBO、近景三个图层，避免把整张场景伪装成 3D。
- 舱体保持固定；任务图像只在中央窗内切换，并叠加代码实现的玻璃、扫描光和色彩反馈。
- 任务启动时放大当前任务图像，1.2 秒完成视窗接管；火星样板任务随后进入独立的任务模拟工作台。
- 所有文字、按钮、标签与状态均使用真实 DOM，不烘焙在图片中。
